Sem patří screenshoty (PNG, 16:9, ideálně 1280x720) pro galerii na Modrinthu a Spigotu.

Agent nemá Minecraft klient, takže skutečné herní screenshoty pořizuje člověk
(`./gradlew runServer` + klient). Agent může generovat:
- mockupy GUI/chatu/tabulek jako HTML -> PNG (viz scripts/render-assets.sh, režim html),
- diagramy a ilustrace jako SVG.
Mockupy vždy označ v popisu galerie jako "illustration", nesmí vydávat umělý obrázek za herní screenshot.
