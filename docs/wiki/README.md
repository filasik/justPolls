# Wiki source

These pages are the source of the [GitHub wiki](https://github.com/filasik/justPolls/wiki). Page links use wiki syntax (`[Text](Page-Name)`), so they work on the wiki, not when browsing this folder.

Edit the pages here, not in the wiki: every push to `main` that touches `docs/wiki/` runs the **Wiki** workflow (`.github/workflows/wiki.yml`), which copies these files to the wiki and removes wiki pages that no longer exist here. This README is not published. The workflow can also be started by hand from the Actions tab.
